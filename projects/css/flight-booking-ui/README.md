# Flight Booking UI

## Project Overview
A travel/flight booking user interface built with HTML, CSS, and a little JavaScript. A
practice project focused on laying out a richer, interactive booking screen.

## Features
- Flight/travel booking interface
- Assets (images/fonts) in the `assets/` folder
- Some interactivity via `script.js`

## Technologies Used
- HTML5
- CSS3
- JavaScript (light interactivity)

## Folder Structure
```
flight-booking-ui/
├── index.html    # the booking UI
├── styles.css    # styling
├── script.js     # interactivity
├── assets/       # images / fonts
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- Laying out a more complex, real-world UI with CSS.
- Organizing assets in a dedicated folder.
- Adding light interactivity with JavaScript.

## Resume Value
Booking interfaces are common, detail-heavy UIs. This shows I can build a polished,
multi-part screen and organize its assets.
