# Exercise: Bootstrap Form Layout

## Goal
Create a clean, styled contact form using Bootstrap form classes, centered in a
responsive column.

## Bootstrap concepts practiced
- Styled form controls
- Labels and field spacing
- Select dropdowns and checkboxes the Bootstrap way
- Centering a form with the grid
- Responsive form width across breakpoints

## Important classes used
- `container`, `row`, `justify-content-center`
- `col-12`, `col-md-8`, `col-lg-6`
- `form-label`, `form-control`, `form-select`
- `form-check`, `form-check-input`, `form-check-label`
- `mb-3`, `btn btn-primary`

## Difficulty
Beginner+
