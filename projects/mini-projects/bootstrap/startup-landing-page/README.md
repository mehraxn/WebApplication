# Startup Landing Page

## Project Overview
A modern, responsive landing page for a fictional SaaS startup called "Nimbus." It follows
the classic marketing-page flow: hero → features → pricing → FAQ → call to action → footer,
using Bootstrap components throughout.

## Features
- Sticky navbar with a call-to-action button
- Hero section with headline and dual CTAs
- Feature cards (three-column responsive grid)
- Pricing section with a highlighted plan
- FAQ accordion (collapsible questions)
- Call-to-action section
- Footer

## Technologies Used
- HTML5
- Bootstrap 5 (via CDN)
- Minimal custom CSS (hero spacing only)
