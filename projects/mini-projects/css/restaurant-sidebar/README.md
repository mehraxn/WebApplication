# Restaurant Sidebar

## Project Overview
A restaurant dashboard sidebar built with HTML and CSS, with a logo, navigation links,
and a profile area. A practice project focused on building a vertical navigation panel.

## Features
- Vertical sidebar navigation
- Logo and profile section (images in `assets/`)
- Navigation links

## Technologies Used
- HTML5
- CSS3

## Folder Structure
```
restaurant-sidebar/
├── index.html    # the sidebar layout
├── style.css     # styling
├── assets/       # logo and profile images
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- Building a vertical sidebar navigation with CSS.
- Combining a logo, links, and a profile area cleanly.
- Structuring a dashboard-style layout.

## Resume Value
Sidebars are a core part of admin and dashboard UIs. This shows I can build a clean,
structured navigation panel.
