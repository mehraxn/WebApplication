# Personal Portfolio

## Project Overview
A responsive personal portfolio website built with Bootstrap. It's a single-page site with
a sticky navbar and smooth-scrolling sections: hero, about, skills, projects, contact, and
footer — the standard structure a developer uses to present themselves.

## Features
- Responsive navbar with mobile toggler and smooth scroll
- Hero section with call-to-action buttons
- About section with an avatar
- Skills section (responsive grid of skill tiles)
- Projects section (Bootstrap cards with badges and buttons)
- Contact section with a styled form
- Footer

## Technologies Used
- HTML5
- Bootstrap 5 (via CDN)
- Minimal custom CSS (smooth scroll + hero spacing only)

## How to Run or Open
Open `index.html` directly in any web browser. Bootstrap loads from its CDN, so an internet
connection is needed. Resize the window to see the responsive behavior.
