# Bootstrap Responsive Layout Demo

## Project Overview
A demonstration of building a responsive page layout with Bootstrap. A practice project
focused on combining the grid and utilities so a page adapts across screen sizes.

## Features
- Responsive page layout
- Uses Bootstrap grid and utility classes
- Adapts across mobile, tablet, and desktop

## Technologies Used
- HTML5
- Bootstrap 5
- A little custom CSS (`styles.css`)

## Folder Structure
```
responsive-layout-demo/
├── index.html    # the layout demo
├── styles.css    # small custom styles
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser. Bootstrap loads from its CDN, so an
internet connection is needed. Resize the window to see the responsive behavior.

## What I Learned
- Combining the Bootstrap grid with utility classes for layout.
- How a layout reflows at different breakpoints.
- Building responsive pages without writing much custom CSS.

## Resume Value
Responsive layout is the main reason teams reach for Bootstrap. This shows I can assemble
an adaptive page quickly using the framework.
