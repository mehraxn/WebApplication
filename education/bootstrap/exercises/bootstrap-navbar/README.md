# Exercise: Bootstrap Navbar

## Goal
Create a responsive Bootstrap navbar with a brand, links, and a sign-in button that
collapses into a hamburger toggler on small screens.

## Bootstrap concepts practiced
- The navbar component
- Responsive collapse (`navbar-expand-md`)
- The toggler and collapsible menu (needs the JS bundle)
- Dark theme colors
- Aligning items with utilities (`me-auto`)

## Important classes used
- `navbar`, `navbar-expand-md`, `navbar-dark`, `bg-dark`
- `container-fluid`, `navbar-brand`
- `navbar-toggler`, `navbar-toggler-icon`
- `collapse`, `navbar-collapse`
- `navbar-nav`, `nav-item`, `nav-link`, `active`
- `data-bs-toggle="collapse"`, `data-bs-target`
- `me-auto`, `btn btn-primary`
