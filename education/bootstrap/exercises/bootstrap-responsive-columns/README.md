# Exercise: Bootstrap Responsive Columns

## Goal
Create a layout that shows 1 column on mobile, 2 columns on tablets, and 3 columns on
desktop using only Bootstrap grid classes.

## Bootstrap concepts practiced
- Mobile-first responsive columns
- Combining multiple column classes on one element
- How breakpoints (`md`, `lg`) change the layout
- Grid gutters and background/spacing utilities

## Important classes used
- `container`, `row`, `g-3`
- `col-12` (1 per row on phones)
- `col-md-6` (2 per row from md up)
- `col-lg-4` (3 per row from lg up)
- `p-4`, `rounded`, `text-center`, `bg-*`, `text-white`, `text-dark`
