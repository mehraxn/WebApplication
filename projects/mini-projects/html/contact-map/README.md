# Contact Map Page

## Project Overview
A "Contact Us" page that includes an embedded map alongside contact information. A
practice project focused on embedding external content with an `<iframe>` and laying out
contact details in HTML.

## Features
- Contact information section
- Embedded map (via `<iframe>`)
- Simple, structured HTML layout

## Technologies Used
- HTML5
- Embedded map through an `<iframe>`

## Folder Structure
```
contact-map/
├── index.html    # the contact + map page
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser. An internet connection is needed for the
embedded map to load.

## What I Learned
- How to embed an external page (a map) with `<iframe>`.
- Organizing contact details in a clear, structured way.
- Combining embedded content with regular page content.

## Resume Value
Demonstrates embedding third-party content (maps) — a common requirement on business and
contact pages.
