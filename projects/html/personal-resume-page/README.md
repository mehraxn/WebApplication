# Personal Resume Page

## Project Overview
A single-page, semantic HTML resume / CV. It presents a developer's profile, education,
skills, projects, experience, and contact links in a clean, well-structured document that
reads clearly even without any CSS.

## Features
- Name and professional title
- Short profile / summary
- Education section
- Skills section (grouped: front-end, back-end, tools)
- Projects section
- Experience section
- Contact links (email, GitHub, LinkedIn)
- Fully semantic HTML structure with in-page navigation

## Technologies Used
- HTML5
- Semantic markup (no CSS yet — structure only)

Open `index.html` directly in any web browser — no server or build step needed.

## What I Learned
- How to structure a real document with semantic HTML (`header`, `section`, `nav`, `footer`).
- Using headings and landmarks so the page has a clear outline.
- Organizing content logically into resume sections.

## Resume Value
Shows I can structure a real document with semantic, accessible HTML, and build the one
page every developer needs — their own resume.
