# Questionnaire

## Project Overview
A questionnaire / survey form built with HTML and CSS. A practice project focused on
laying out and styling a multi-question form.

## Features
- Multi-question survey form
- Various input types (choices, text)
- Styled, readable layout

## Technologies Used
- HTML5
- CSS3

## Folder Structure
```
questionnaire/
├── index.html    # the questionnaire form
├── style.css     # styling
├── assets/       # fonts / images
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- Structuring a longer form with multiple questions.
- Styling groups of inputs consistently.
- Keeping a long form readable and organized.

## Resume Value
Surveys and questionnaires are common data-collection tools. This shows I can build and
style a longer, structured form.
