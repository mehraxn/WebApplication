# Contact / Login Form (CSS)

## Project Overview
A styled login/contact form built with HTML and CSS. A practice project focused on
styling form controls and centering a form card on the page.

## Features
- Styled form with inputs and a button
- Custom fonts (bundled in the `font/` folder)
- Centered card layout

## Technologies Used
- HTML5
- CSS3
- Custom web font

## Folder Structure
```
contact-form/
├── index.html    # the form page
├── style.css     # styling
├── font/         # bundled font files
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- How to style form inputs and buttons consistently.
- Centering a form card with CSS.
- Bundling and applying a custom font.

## Resume Value
Forms appear in almost every app. This shows I can turn a plain form into a clean, styled
interface with CSS.
