# Retro Auto Pong

## Project Overview
A small retro-style "auto Pong" page — a fun practice project that recreates the classic
Pong look in the browser. A lightweight experiment beyond static content.

## Features
- Retro Pong-themed page
- Self-contained in a single HTML file
- Playful, minimal styling

## Technologies Used
- HTML5
- (Any styling/logic is contained within `index.html`)

## Folder Structure
```
retro-pong/
├── index.html    # the Pong page
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.
