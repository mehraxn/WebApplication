# Spanish Pronunciation Guide

## Project Overview
An HTML page that acts as a small Spanish pronunciation guide, pairing text with an audio
clip. A practice project focused on embedding media (audio) in a page.

## Features
- Pronunciation guide content
- Embedded audio playback (`spanish-audio.mp3`)
- Simple, structured HTML

## Technologies Used
- HTML5
- HTML `<audio>` media element

## Folder Structure
```
spanish-pronunciation-guide/
├── ptoject.HTML       # the guide page (entry file)
├── spanish-audio.mp3  # audio clip
├── README.md          # this file
└── screenshots/       # add screenshots here
```

## How to Run or Open
Open `ptoject.HTML` directly in any web browser — no server needed. Make sure the
`spanish-audio.mp3` file stays in the same folder so the audio plays.

## What I Learned
- How to embed and control audio with the `<audio>` element.
- Pairing text content with media on a page.
- Keeping media files alongside the HTML that references them.

## Resume Value
Shows I can incorporate media (audio) into web pages — useful for educational and content
sites.
