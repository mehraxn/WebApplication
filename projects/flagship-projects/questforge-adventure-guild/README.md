# QuestForge — Fantasy Adventure Guild Platform

QuestForge is a standalone Flask portfolio project for browsing and managing a fictional guild's weekly adventure sessions.

The planned application uses Flask, Flask-Login, SQLite, Jinja templates, Bootstrap, and custom CSS. This initial scaffold contains placeholder pages and module boundaries; complete authentication, database tables, and business rules will be added in later phases.

## Run locally

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000` in a browser.
