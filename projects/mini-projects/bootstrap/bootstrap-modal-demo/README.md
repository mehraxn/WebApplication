# Bootstrap Modal Demo

## Project Overview
A demonstration of the Bootstrap modal component — a button that opens a pop-up dialog. A
practice project focused on Bootstrap's interactive JavaScript components.

## Features
- Button that triggers a modal
- Modal with header, body, and footer
- Close/dismiss behavior

## Technologies Used
- HTML5
- Bootstrap 5 (CSS + JS bundle)
- A little custom CSS (`style.css`)

## Folder Structure
```
bootstrap-modal-demo/
├── index.html    # the modal demo
├── style.css     # small custom styles
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser. Bootstrap loads from its CDN, so an
internet connection is needed for the modal to work.

## What I Learned
- How to trigger a modal with `data-bs-toggle` and `data-bs-target`.
- The modal structure: header, body, and footer.
- That interactive components need the Bootstrap JS bundle.

## Resume Value
Modals are a common interactive UI pattern. This shows I can use Bootstrap's JavaScript
components, not just its layout classes.
