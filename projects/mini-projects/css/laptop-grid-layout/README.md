# Laptop Grid Layout

## Project Overview
A product grid showcasing laptops, built with HTML and CSS (with a little JavaScript). A
practice project focused on building a responsive grid of product cards.

## Features
- Grid of laptop product cards
- Product images in the `assets/` folder
- Some interactivity via `script.js`

## Technologies Used
- HTML5
- CSS3 (grid/flex layout)
- JavaScript (light interactivity)

## Folder Structure
```
laptop-grid-layout/
├── index.html    # the product grid
├── style.css     # styling
├── script.js     # interactivity
├── assets/       # product images
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

- Managing image assets for a catalog-style page.
- Adding light interactivity with JavaScript.

## Resume Value

image-based grid layout.
