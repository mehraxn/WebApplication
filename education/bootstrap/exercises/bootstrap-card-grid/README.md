# Exercise: Bootstrap Card Grid

## Goal
Create a responsive grid of cards using Bootstrap's container, row, and column system —
1 card per row on phones, 2 on tablets, and 3 on large screens.

## Bootstrap concepts practiced
- The 12-column grid (`container` → `row` → `col`)
- Responsive column classes across breakpoints
- The card component
- Equal-height cards with `h-100`
- Grid gutters with `g-4`

## Important classes used
- `container`, `row`, `g-4`
- `col-12`, `col-sm-6`, `col-lg-4`
- `card`, `card-body`, `card-title`, `card-subtitle`, `card-text`
- `h-100`, `text-muted`, `btn btn-primary`

Beginner+
