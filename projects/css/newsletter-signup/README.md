# Newsletter Signup

## Project Overview
A newsletter sign-up section built with HTML and CSS. A practice project focused on
creating an attractive call-to-action block with an email input.

## Features
- Newsletter sign-up section
- Email input and subscribe button
- Assets (images/fonts) in the `assets/` folder

## Technologies Used
- HTML5
- CSS3

## Folder Structure
```
newsletter-signup/
├── index.html    # the sign-up section
├── styles.css    # styling
├── assets/       # images / fonts
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- Designing an eye-catching call-to-action section.
- Styling an inline email input with a button.
- Using assets to enhance a simple section.

## Resume Value
Sign-up / call-to-action blocks appear on almost every marketing site. This shows I can
build a focused, conversion-oriented component.
