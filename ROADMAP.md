# Repository Roadmap

A structured learning and portfolio roadmap for completing this repository into a
junior web developer / junior Flask developer resume asset.

---

## 1. Goal of the Repository

This repository is a **structured learning and project portfolio** covering the core
front-end and back-end web development stack:

- **HTML** — structure and content
- **CSS** — styling and layout
- **Bootstrap** — rapid, responsive UI
- **Flask** — Python web application development

It has two purposes that work together:

1. **Learn** — build a solid, documented foundation in each technology through notes
   and exercises (in `education/`).
2. **Prove** — turn that knowledge into finished, presentable projects (in `projects/`)
   that a recruiter can open, read, and run.

The end state is a repository that reads clearly to a hiring manager: organized notes
that show *how* the skills were learned, and completed projects that show *what* can be
built with them.

---

## 2. Education Plan

The `education/` folder contains **notes and exercises** for each topic. Notes capture
the concept in your own words; exercises are small, focused files that practice a single
idea. Work through the topics below roughly in order — later topics assume the earlier
ones.

### HTML
- Document structure (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Forms (inputs, labels, `select`, `textarea`, buttons)
- Tables (`<table>`, `<thead>`, `<tbody>`, `<th>`, rows and cells)
- Media (images, audio, video, `figure`/`figcaption`)
- Links (internal, external, anchors, `mailto`)
- Accessibility basics (alt text, labels, ARIA roles, keyboard navigation)
- SEO basics (meta tags, titles, heading hierarchy, descriptive URLs)

### CSS
- Selectors (element, class, id, attribute, pseudo-classes)
- Colors and typography (units, fonts, line height, text styling)
- Box model (margin, border, padding, content, `box-sizing`)
- Display (block, inline, inline-block, none)
- Positioning (static, relative, absolute, fixed, sticky, z-index)
- Flexbox (main/cross axis, alignment, wrapping, ordering)
- Grid (rows, columns, areas, gaps, responsive tracks)
- Responsive design (media queries, mobile-first, relative units)
- Transitions and animations (`transition`, `@keyframes`, `transform`)
- Forms and cards (styling inputs, buttons, and card components)
- CSS variables (custom properties, theming, reuse)

### Bootstrap
- Grid system (rows, columns, breakpoints)
- Containers (fixed vs. fluid)
- Spacing utilities (margin/padding helper classes)
- Buttons (variants, sizes, states)
- Cards (headers, bodies, images, groups)
- Navbar (branding, links, toggler, responsive collapse)
- Forms (form controls, validation styling, input groups)
- Modal (triggers, dialogs, backdrops)
- Carousel (slides, controls, indicators)
- Responsive layouts (combining grid, utilities, and components)

### Flask
- Routes (URL rules, dynamic segments)
- View functions (returning responses)
- Templates (rendering HTML from Python)
- Jinja (variables, loops, conditionals, template inheritance)
- Static files (CSS, JS, images via `static/`)
- Forms (rendering and receiving form data)
- POST/GET (handling both methods, request object)
- Flash messages (user feedback across requests)
- SQLite (connecting and querying a database)
- CRUD (create, read, update, delete)
- Validation (checking and sanitizing input)
- Project structure (organizing routes, templates, static files, and config)

## 4. Resume Value

Completing this repository demonstrates to a recruiter that you can:

- **Write clean, semantic HTML** with accessibility and SEO awareness — not just tags
  that happen to render.
- **Style and lay out pages with modern CSS** (Flexbox, Grid, responsive design,
  animations) without relying only on frameworks.
- **Build responsive UIs quickly with Bootstrap**, showing familiarity with a widely
  used industry framework.
- **Develop full back-end web applications in Flask**, including routing, templating,
  forms, and database-backed CRUD.
- **Work with a database (SQLite)** to persist and manage real data.
- **Structure a project** the way real applications are organized.
- **Document and present work** through READMEs, screenshots, and live demos.

Together, the notes prove you understand the fundamentals, and the projects prove you
can ship working software — exactly the combination a junior developer role looks for.
