# Attribution and License Notes

This image pack avoids random copyrighted Google images.

It uses local SVG assets so the project can run offline and remain safe for GitHub.

## Game-icons.net assets

Some central icon shapes are based on SVG assets by **game-icons.net** and are licensed under **CC Attribution / CC BY**.

Game-icons project:
- https://game-icons.net/
- https://github.com/game-icons/icons

The wrapped QuestForge versions are modified by adding:
- gradient backgrounds
- custom colors
- title/subtitle typography
- card-style layout
- project-specific filenames
