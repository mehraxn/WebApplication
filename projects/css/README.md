# CSS Projects

Polished, responsive portfolio projects built with plain **HTML and CSS** — no
Bootstrap or JavaScript frameworks. Each is a self-contained folder with an
`index.html`, a `style.css`, and its own `README.md` (overview, features, technologies,
CSS concepts used, folder structure, resume value, and future improvements). All use
CSS variables for repeated colors/spacing and are responsive.

## Portfolio projects

Polished, resume-ready projects built for this portfolio:

| Project | Description | Key CSS concepts |
|---------|-------------|------------------|
| [responsive-pricing-cards/](responsive-pricing-cards/) | Responsive pricing page with a highlighted plan | Flexbox, CSS variables, hover transitions, positioning |
| [admin-dashboard-layout/](admin-dashboard-layout/) | Static admin dashboard with sidebar and stats | CSS Grid + Flexbox, responsive layout, variables |
| [animated-login-page/](animated-login-page/) | Centered login page with transitions | Flexbox centering, `@keyframes`, focus/hover states |

## How to view
Open any project's `index.html` directly in a web browser. No build step or server is
required — these are static HTML/CSS pages. Resize the window to see the responsive
behavior.
