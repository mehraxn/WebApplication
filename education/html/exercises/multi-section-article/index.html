How I Started Learning Web Development

Published on July 2, 2026 by a junior developer.

Where I Began

I started with HTML because it is the foundation of every web page. Before styling or logic, you need structure.

My first goals were simple:

  • Understand the page skeleton
  • Learn semantic tags
  • Build a working form

My Study Steps

  1. Read the notes for a topic
  2. Write a small exercise
  3. Review what I got wrong
"The best way to learn to code is to write code every day."

Helpful Resources

The docs I used most were the MDN Web Docs. They explain every tag with examples.
