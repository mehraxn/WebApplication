# Exercise: Bootstrap Alerts & Badges

## Goal
Create a page that demonstrates Bootstrap alerts (including a dismissible one) and
badges in several styles.

## Bootstrap concepts practiced
- The alert component and its color variants
- Dismissible alerts (needs the JS bundle)
- The badge component and color variants
- Pill badges and badges inside buttons/headings
- Utility text colors for contrast

## Important classes used
- `alert`, `alert-success`, `alert-danger`, `alert-warning`, `alert-info`, `alert-primary`
- `alert-dismissible`, `fade`, `show`, `btn-close`, `data-bs-dismiss="alert"`
- `badge`, `bg-primary`, `bg-success`, `bg-danger`, `bg-warning`
- `rounded-pill`, `text-dark`, `bg-light`
