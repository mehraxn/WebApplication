# Bootstrap Projects

Portfolio and practice projects built with **Bootstrap 5** (loaded via CDN). The
portfolio projects are polished, resume-ready pages; the demos are smaller practice
pieces. Custom CSS is kept to a minimum — the layouts rely on Bootstrap classes.

## Portfolio projects

| Project | Description | Bootstrap components |
|---------|-------------|----------------------|
| [personal-portfolio/](personal-portfolio/) | Responsive personal portfolio site | Navbar, grid, cards, buttons, badges, form |
| [startup-landing-page/](startup-landing-page/) | Modern SaaS landing page ("Nimbus") | Navbar, hero, cards, accordion, pricing, footer |
| [admin-dashboard/](admin-dashboard/) | Static admin dashboard | Grid, sidebar, cards, table, badges, progress bars |

## How to view
Open any project's `index.html` (or the demo's `.html` file) directly in a browser. No
build step is needed — Bootstrap loads from its CDN. Resize the window to see the
responsive behavior.
