# Invitation Form

## Project Overview
An HTML form for collecting invitation/RSVP details. A practice project focused on
building a form with a variety of input fields and correct labels.

## Features
- Invitation / RSVP form
- Multiple input types (text, and other fields)
- Labels connected to inputs
- Submit button

## Technologies Used
- HTML5 forms


## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- How to build an HTML form with several input types.
- Connecting `<label>` elements to inputs for accessibility.
- Using the `name` attribute so field values can be submitted.

## Resume Value
Forms are the core way users send data to a site. This shows I can build a structured,
accessible form — the foundation for later Flask form handling.
