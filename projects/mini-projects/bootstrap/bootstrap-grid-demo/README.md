# Bootstrap 12-Column Grid Demo

## Project Overview
A demonstration of Bootstrap's 12-column grid system, showing how rows and columns divide
the page and adapt across screen sizes. A practice project focused on the fundamentals of
the Bootstrap grid.

## Features
- Examples of the 12-column grid
- Rows and columns of different widths
- Responsive column behavior

## Technologies Used
- HTML5
- Bootstrap 5
- A little custom CSS (`grid-demo.css`)

## Folder Structure
```
bootstrap-grid-demo/
├── bootstrap-12-column-demo.html  # the grid demo (entry file)
├── grid-demo.css                  # small custom styles
├── README.md                      # this file
└── screenshots/                   # add screenshots here
```

## How to Run or Open
Open `bootstrap-12-column-demo.html` directly in any web browser. Bootstrap loads from its
CDN, so an internet connection is needed.

## What I Learned
- How Bootstrap divides each row into 12 columns.
- Using `col-*` classes to set column widths.
- How columns stack and reflow responsively.

## Resume Value
The grid is the foundation of every Bootstrap layout. This shows I understand the core
system that all Bootstrap responsiveness is built on.
