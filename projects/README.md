# Projects

This folder holds the hands-on projects for the portfolio, grouped by technology. Each
project is a self-contained folder with its own `README.md` (Project Overview, Features,
Technologies Used, Folder Structure, How to Run or Open, What I Learned, Resume Value, and
Future Improvements) and a `screenshots/` folder ready for images.

- **HTML** → `html/` — structure and semantic markup
- **CSS** → `css/` — styling, layout, and responsive design
- **Bootstrap** → `bootstrap/` — rapid, responsive UI with a framework
- **Flask** → `flask/` — full back-end web applications with SQLite

Category-level indexes with more detail live in each folder's own README:
[html/README.md](html/README.md) · [css/README.md](css/README.md) ·
[bootstrap/README.md](bootstrap/README.md) · [flask/README.md](flask/README.md)

## Strongest resume projects (⭐)
These are the most complete, portfolio-ready projects to highlight to a recruiter:

1. **[flask/task-manager-sqlite/](flask/task-manager-sqlite/)** — a complete Flask CRUD app
   (routing, templates, validation, flash, SQLite). The strongest back-end proof.
2. **[flask/booking-reservation-app/](flask/booking-reservation-app/)** — two related tables,
   live capacity checks, and date validation. Shows real business logic.
3. **[flask/expense-tracker/](flask/expense-tracker/)** — CRUD plus SQL aggregation
   (`SUM`/`GROUP BY`) and filtering.
4. **[flask/blog-crud-app/](flask/blog-crud-app/)** — CRUD plus search and timestamp tracking.
5. **[bootstrap/personal-portfolio/](bootstrap/personal-portfolio/)** — a full responsive
   portfolio site that ties the front-end skills together.
6. **[css/admin-dashboard-layout/](css/admin-dashboard-layout/)** — Grid + Flexbox mastery in
   a realistic dashboard, no framework.

Together these show the full stack a junior web / Flask developer is expected to know:
semantic HTML, modern CSS, responsive Bootstrap UIs, and database-backed Flask applications.
