# Exercise: Bootstrap Modal Practice

## Goal
Create a button that opens a Bootstrap modal dialog with a header, body, and footer
actions.

## Bootstrap concepts practiced
- The modal component
- Triggering a modal with data attributes (no custom JavaScript)
- Modal structure: header, body, footer
- Closing a modal with the close button and a dismiss button
- Why the Bootstrap JS bundle is required for interactive components

## Important classes used
- `btn`, `btn-primary`, `btn-secondary`
- `data-bs-toggle="modal"`, `data-bs-target="#exampleModal"`
- `modal`, `fade`, `modal-dialog`, `modal-content`
- `modal-header`, `modal-title`, `modal-body`, `modal-footer`
- `btn-close`, `data-bs-dismiss="modal"`
