# Class Schedule Table

## Project Overview
An HTML page that displays a weekly class schedule as a table. It's a practice project
focused on structuring real tabular data (days, times, and subjects) with clean,
semantic HTML.

## Features
- Weekly schedule laid out as an HTML table
- Header row for the days/columns
- Rows of class data
- Simple, readable structure
