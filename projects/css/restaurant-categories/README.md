# Restaurant Categories

## Project Overview
A restaurant category section built with HTML and CSS, showing food categories as cards
or tiles. A practice project focused on a clean, icon-driven category layout.

## Features
- Grid/row of restaurant categories
- Category icons/images in the `assets/` folder
- Clean, tile-based layout

## Technologies Used
- HTML5
- CSS3

## Folder Structure
```
restaurant-categories/
├── index.html    # the categories section
├── styles.css    # styling
├── assets/       # category icons/images
├── README.md     # this file
└── screenshots/  # add screenshots here
```

## How to Run or Open
Open `index.html` directly in any web browser — no server needed.

## What I Learned
- Building a tile/card-based category layout.
- Using icons/images to make categories scannable.
- Arranging repeated items evenly with CSS.

## Resume Value
Category navigation is central to food-delivery and e-commerce apps. This shows I can
build a clean, browsable category layout.
