# Exercise: Multi-Section Article

## Goal
Build a blog-style article page that combines headings, paragraphs, lists, a
quote, links, and an image inside a proper semantic structure.

## Concepts practiced
- Wrapping a post in `<article>` with nested `<section>`s
- Heading hierarchy (`h1` → `h2` → `h3`)
- Paragraphs with `<p>`
- Unordered list `<ul>` vs ordered list `<ol>`
- `<blockquote>` for a standout quote
- Links with `<a href>` (including an external link)
- `<figure>` / `<figcaption>` for an image with a caption
- `<nav>` for in-page navigation

## Files included
- `index.html` — the blog article page
- `README.md` — this file

## What I learned
- An `<article>` can contain multiple `<section>`s, each with its own subheading.
- Use `<ul>` when order doesn't matter and `<ol>` when steps happen in sequence.
- `<blockquote>` marks up quoted text semantically, not just visually.
- Combining several elements (headings, lists, quotes, links, images) is how real
  content pages are built.
