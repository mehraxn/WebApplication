The projects are divided into two groups:

## Flagship Projects

Complete, larger projects that demonstrate full application structure, backend logic, database usage, authentication, and realistic user flows.

### Walkly — Free Walking Tours Platform

**Path:** [`flagship-projects/walkly-free-walking-tours/`](flagship-projects/walkly-free-walking-tours/)

**Description:**
A full-stack Flask web application for discovering, booking, and managing free walking tours. It includes user authentication, role-based access, guide dashboards, participant reservations, capacity checks, cancellation rules, completed-tour reporting, SQLite storage, and an admin dashboard.

**Technologies:**
Flask, SQLite, Flask-Login, Jinja, HTML5, CSS3, Bootstrap.
