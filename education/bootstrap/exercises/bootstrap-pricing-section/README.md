# Exercise: Bootstrap Pricing Section

## Goal
Build a pricing section with three plans using Bootstrap cards and the grid, with the
middle "Pro" plan highlighted.

## Bootstrap concepts practiced
- Combining the grid and card components
- Equal-height cards (`h-100`) with a bottom-aligned button
- Highlighting a card with border utilities and a badge
- Flexbox utilities inside a card (`d-flex flex-column`, `mt-auto`)
- Typography and list utilities

## Important classes used
- `container`, `row`, `g-4`, `justify-content-center`
- `col-12`, `col-md-6`, `col-lg-4`
- `card`, `h-100`, `card-body`, `card-title`
- `d-flex`, `flex-column`, `mt-auto`
- `display-6`, `fs-6`, `text-muted`, `list-unstyled`
- `border-primary`, `border-2`, `badge bg-primary`
- `btn btn-primary`, `btn-outline-primary`
