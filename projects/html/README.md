# HTML Projects

Polished, HTML-only portfolio projects. Each is a self-contained folder with an
`index.html` and its own `README.md` (overview, features, technologies, folder
structure, resume value, and future improvements). These projects focus on clean,
semantic, accessible structure — styling with CSS comes in a later stage.

## Projects

| Project | Description | Key concepts |
|---------|-------------|--------------|
| [personal-resume-page/](personal-resume-page/) | A semantic HTML resume / CV page | Sections, headings, lists, contact links, in-page nav |
| [restaurant-menu-page/](restaurant-menu-page/) | A restaurant menu with categories, prices, and hours | `section`/`article` per dish, dietary labels, data table, `address` |
| [blog-article-layout/](blog-article-layout/) | A clean blog article layout | `article`, table of contents, `time` metadata, `blockquote`, `aside` |

## How to view
Open any project's `index.html` directly in a web browser. No build step or server
is required — these are static HTML pages.
